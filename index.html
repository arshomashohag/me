01

Shop 360

SaaS Retail management Cloud architecture

An all-in-one shop management platform: products, inventory, sales, purchases, transfers, returns, customers, users and billing running as one system instead of five disconnected tools.

Role
Engineering and product build-out
Shape
Multi-tenant web application with point-of-sale workflows

The problem

Small and medium retailers run inventory, sales, purchasing and store operations across tools that do not talk to each other. The reconciliation happens in someone's head, at closing time.

The solution

One platform where a sale moves stock, a purchase updates cost, a transfer stays traceable between outlets, and a return reverses all of it correctly.

My contribution

Backend architecture and API design, data modelling for inventory and sales workflows, authentication and role handling, multi-tenancy, and the cloud infrastructure it runs on.

03

Orchestration engine for cloud media resources

Workflow orchestration Python Terraform Lambda DynamoDB

Developed and productized an engine that stands up, runs and tears down AWS resources for a streaming channel from a configurable workflow template — so a channel becomes a described intent rather than a manual sequence of console steps.

  • Template-driven configuration: one description defines the resource set for a workflow.
  • Lifecycle management across the pre-transmission, transmission and post-transmission phases.
  • Event-driven state handling, with failure paths treated as a first-class case.
  • CI/CD with automated testing around every deployment.

3D web Three.js Angular Node.js

At BJIT Ltd. I built modules for a 3D web application used to inspect plant models in the browser: a comments manager for annotated screenshots, a markup manager for drawing highlights onto models, a measurement panel for interactive geometry, and a point cloud renderer in Three.js.
